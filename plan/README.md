# Plan

Planning and design docs for Trace. Nothing here is code — it's the place to
write down what we intend to build before it lands in `src/`.

- `roadmap.md` — current state and the next chunks of work.
- `globe-view.md` — plan for the SwiftUI 3D globe: satellite texture,
  atmosphere, star background, and markers.
- `railway-bucket.md` — plan for object storage in the Railway `trace-bucket`:
  presigned uploads and reads, the `media_objects` registry, and the auth work
  it depends on.

Add one Markdown file per feature or decision as they come up.
